Проблема в том, что папка sh/bin/ уже проиндексирована Git до добавления в .gitignore. Когда файл или папка уже отслеживается Git, добавление её в .gitignore не прекращает отслеживание. Необходимо удалить папку из индекса Git, сохранив её в файловой системе.

Для решения этой проблемы выполните следующую команду:

bash
git rm -r --cached sh/bin/
После этого добавьте изменения в индекс и сделайте коммит:

bash
git add .gitignore
git commit -m "Удаление sh/bin из индекса и обновление .gitignore"
Это удалит папку sh/bin/ из Git индекса, но сохранит её в файловой системе, и теперь Git будет игнорировать её содержимое согласно правилам в .gitignore.
