Чтобы проверить состояние памяти, дисков и потребление ресурсов на сервере с Ubuntu через SSH, вы можете использовать несколько утилит и команд. Вот список наиболее распространенных команд:

### 1. Проверка состояния памяти

- **Команда `free`**: Показать использование памяти.
  ```bash
  free -h
  ```

- **Команда `top`**: Отображает динамическое состояние системы, включая использование памяти и процессора.
  ```bash
  top
  ```

- **Команда `htop`**: Более удобный вариант `top`, если установлен (может потребоваться установка).
  ```bash
  sudo apt install htop
  htop
  ```

### 2. Проверка состояния дисков

- **Команда `df`**: Показывает использование дискового пространства.
  ```bash
  df -h
  ```

- **Команда `du`**: Анализирует дисковое пространство, используемое отдельными файлами и директориями. Например, узнать размеры папок в текущем каталоге:
  ```bash
  du -sh *
  ```

- **Команда `lsblk`**: Отображает информацию о всех блоковых устройствах.
  ```bash
  lsblk
  ```

- **Команда `fdisk` или `parted`**: Показывает разделы диска и их состояние.
  ```bash
  sudo fdisk -l
  ```

### 3. Общее потребление ресурсов

- **Команда `vmstat`**: Предоставляет информацию о системе, включая память, процессы, буферы и кэш.
  ```bash
  vmstat 1
  ```

- **Команда `mpstat`**: Отображает статистику использования процессора.
  ```bash
  sudo apt install sysstat  # Установить, если не установлено
  mpstat
  ```

- **Команда `iostat`**: Предоставляет информацию о входах/выходах и использовании процессора.
  ```bash
  iostat -x 1
  ```

### 4. Мониторинг системы

- **Команда `sar`**: Используется для сбора, отчета или сохранения системной активности.
  ```bash
  sudo apt install sysstat  # Установить, если не установлено
  sar -u 1
  ```

Эти команды помогут вам оценить текущее состояние системы и выявить возможные узкие места в использовании ресурсов.
